# 蒸汽 / ZHENGQI 标识

FlatPack3D 由蒸汽（ZHENGQI）制作。本目录是项目用到的标识文件。

| 文件 | 用途 |
|---|---|
| `steam-icon-512.png` | 方形图标，README 头部、介绍图 |
| `steam-icon-256.png`、`steam-icon-128.png` | 中等尺寸 |
| `steam-icon-64.png` | 页面右下角"by 蒸汽"（显示为 20 px） |
| `steam-icon-32.png` | 网站图标等小尺寸 |

- 来源：作者已有的应用图标（Z 形标识 + "STEAM workstation" 字样），原图 1254 × 1254。这里的版本只做了两处处理：去掉透明边缘上的杂点、按白色圆角方块裁成正方形，然后缩放成上面几种尺寸。
- 字体：标识是图片，不依赖字体；页面上"by 蒸汽"这几个字用浏览器的系统字体显示，仓库里没有附带字体文件。

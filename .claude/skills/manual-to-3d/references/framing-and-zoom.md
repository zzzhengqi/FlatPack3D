# 取景、放大圆圈与动作

引擎自动处理取景和放大圆圈；数据只需写对零件、五金、动作。这里说明引擎做了什么、检查查什么、出了问题改哪里。

## 取景（主画面）

- 切步骤时，相机按"本步完成后的画面"（已装上的零件、格子示意）的包围盒取景，并避开步骤卡、五金卡、按钮条：先算出画布里不被面板挡住的最大矩形，再沿视线方向找最近的距离让包围盒正好放进去。
- 用户拖动或缩放画面后，自动取景暂停（按钮显示"已暂停"）；单击不算。按 R 或"全景"恢复。
- 备料区里还没放上去的零件如果只露出一半（被画布边缘切掉），这一步先把它移出画面。

## 放大圆圈

**什么时候出现**：本步在动的零件里，有哪一种在主画面上的屏幕面积低于阈值。

- **屏幕面积** = 零件包围盒 8 个角投到画面上的包围矩形的面积（CSS px²）。
- **阈值 `AREA_MIN` = 1600 px²**（约 40 × 40）。
- **细长零件**（最长边 ≥ 次长边的 3 倍：长螺钉、木销、滑轨）改按投影长度折算：投影长 60 px 折合 1600 px²，取面积和折算值中较大的。原因：10 cm 长的螺钉竖着看时投影 60–90 px 长、只有 10 px 宽，面积永远不够，但人看得清。
- **分组**：本步放上的板件合成一组（按合起来的包围盒算，翻转柜体时整个柜体算一组）；五金按种类分组，取画面上最大的那个。

**圈里放什么**：
- 对准面积最小的那一组的第 1 个（数据里 `zoomFocus: { index, page }` 可以指定对准第几个，依据页要写），12 cm 以内的其他小零件一起放进去；剩下离得远的小零件开第二个圆圈（最多两个）。
- **视野**约为焦点零件尺寸的 3.5 倍，看得到相邻板件的边和角；只有达不到面积阈值时才收紧，最少收紧到圈里最小零件尺寸的 1.5 倍（实际只在手机、笔记本宽度的小圆圈里出现，`narrow-fields.json` 会列出来）。
- **视角**跟着主相机方向；焦点是螺钉、木销这类有装入方向的零件时，从侧面、与轴线约 60° 看；如果焦点和相机之间有板挡着，依次试放平视角、斜对角、只偏一个方向、正对孔口，取前方空得最远的那个。
- **线稿**：白底黑线（与"线稿"视图同样的材质），工具画成实心黑色，本步五金浅灰；被近裁剪面切开的板、包住圈里零件的板画成半透明浅灰，看得见螺钉在木板里的位置。
- **数量标记**：说明书写"2x"的，圈里只显示其中一处，圈顶写"2×"；主画面里另一处同步播放。
- **大小和位置**：直径取画布短边的 42%（手机 55%），110–300 px（桌面约 260–300 px）；在 8 px 网格上找位置，不压步骤卡、五金卡、按钮条和另一个圆圈，挡住柜体越少、离零件越近、缩得越少越好；画一条引线连到零件在柜体上的位置。

## 动作

引擎给本步的五金按顺序播放动作，播完一遍后**本步停留期间一直循环**（停 1.2 秒 → 放回开始的样子 → 再播），主画面和圆圈同步：

| 情况 | 动作 | 工具和箭头 |
|---|---|---|
| 数据 `motions` 里写了（说明书画了箭头） | 按类型：`screw` 边转边拧入、`unscrew` 边转边退出再抽走、`turn` 原地转、`slide` 来回滑动、`tighten` 拧紧、`push` 推入 | 有 `tool` 就显示扳手（`100001` 这类 Z 形内六角）或螺丝刀；圈里画箭头，圈底写"依据 p<页>" |
| 数据没写的螺钉 | 也边转边拧入（螺钉不转拧不进去） | 不显示工具、不画箭头 |
| 敲进去的钉子（`hardware[].drive: "hammer"`） | 推进去，不转 | 无 |
| 其他五金（木销、毡垫、底座、盖帽） | 从外面推进去 | 无（说明书画了直箭头的写 `push` 动作才有箭头） |

- 转向：从钉头一侧看拧入顺时针、拧出逆时针（依据：KALLAX 说明书 p35 与 p33 的扳手箭头方向相反）。
- 每个写进数据的动作都要有依据页（`page` 必须是本步的页），`motionNote` 用一句话写明是哪个箭头，英文译文也要写同样的页码。
- 第一遍播放时，圆圈在本步装五金那一段才出现（板件还在飞、柜体在翻时不显示空圈）。

## 检查（scripts/check-framing.js）

对每个产品、每个件、每条路线、每一步，在三种尺寸（桌面 1280×800、笔记本 1024×680、手机 390×844）下截图，检查：

1. 本步应看到的东西完整在画布内，没有被面板挡住，没有缩得太小（占可用区域的 60% 以上）。
2. 页面不横向溢出（手机上和屏幕宽度比，不是和布局视口比）。
3. 本步在动的每一组零件，在主画面或放大圆圈里的屏幕面积不低于阈值（细长零件按长度折算）。
4. 放大圆圈不出画布、不压面板、两个圆圈不重叠。
5. 备料区零件没有被画布边缘切掉一半。

截图在 `renders/framing/<产品>/<语言>/<尺寸>/`，`narrow-fields.json` 列出视野被收紧到不足 3 倍的圆圈。页面加 `?zoom=0` 会关掉放大圆圈，可用来确认检查能报错。

## 面积够不等于看得懂

检查只量面积。圈里看不看得懂，要靠阶段 6 的对照图：左边说明书这一步，右边 3D 圆圈在动画中途。常见的"面积够但看不懂"：

- 螺钉已经拧到底，圈里只剩一个点（→ 截图要在动画中途；动作循环让它一直有"在孔外"的画面）。
- 圈里只有两块灰色板面，看不出是哪个角（→ 视野要够大、线稿、半透明切面）。
- 主相机从孔的背面看，圈里看到的是板的内侧（→ 侧面视角）。
- 扳手正对镜头，成了一团黑（→ 侧面视角；截图时机换一个）。

## 4. 三份说明书之间的关系

1. **主体和嵌件**：shelf 是 5×5 框体，有 25 个格子；door 和 drawers 都是装进**单个格子**的嵌件，可以任选一些格子安装。shelf 那份说明书里完全没有提到嵌件。两份嵌件说明书的示意图用的是 2×2（步骤图）和 4×4（p3 信息框）的 KALLAX，说明嵌件说明书是通用的，不限定哪种规格的框体。
2. **嵌件的安装方式相同**：都是"折叠外框 → 折成 U 形 → 用定位片在格子底板前沿两侧划线 → 外框推进格子 → 对齐划线 → 用 124386 自攻螺钉固定到格子左右侧壁"。区别在于：
   - door 在外框的一侧装 2 个铰链底座 109221，再把门挂上去；
   - drawers 的外框自带滑轨，两个抽屉要先单独组装。
3. **共用五金编号**：100412（拉手螺钉）、106266（拉手）、107091（防撞垫）、124386（外框固定螺钉）。两份嵌件的定位片编号不同：door 是 131351，drawers 是 123482。
4. **和墙固定件的关系**：两份嵌件 p3 的 ⓘ 信息框画的是：在装了墙固定件的角格（图上标了左上、右上两格）里装嵌件时，要把那个 L 形转角盖帽拿掉，或者不装（✗ 打在盖帽上）。这个盖帽就是 shelf p6 的 115754/118673/118225/119509，墙固定件就是 115753。所以：
   - shelf 用**方案 A** 上墙时，左上、右上两格如果要装嵌件，会和盖帽冲突。
   - **方案 B**（L 角码装在顶板上方）不占格子里面的位置。
   这一条是根据图示判断的。
5. **组装顺序**：先按 shelf 装好框体并上墙，再装嵌件。嵌件的步骤图都是在已经立起来的框体里操作的。
6. **工具**：shelf 和 drawers 都需要锤子（敲木销/钉子），door 只需要十字螺丝刀和铅笔；shelf 另外还需要水平尺。

### shelf p31–p35：方案 B

步骤与第 1 节方案 B 表格一致：p31 角码放在顶板上、铅笔在墙上划线；p32 角码用圆头墙钉固定到墙上；p33 从顶板拧出 2 颗长螺钉 104321/104322；p34 把柜体推到角码下方；p35 把 2 颗长螺钉穿过角码拧回顶板（图中画了 Z 形扳手 100001）。

墙在柜体哪一面，2 倍图上的线索：
- p31：两个角码都放在顶板**左端**，在深度方向前后排开；放大图里角码的竖边沿顶板左端的端面垂下，铅笔在竖边外侧划线。
- p33：拧出来的 2 颗长螺钉也在顶板左端、前后排开，也就是第 1 步顶板与左侧板相接处的那两颗。
- p34：放大图里黑箭头把顶板端面推向角码竖边；整机图的箭头指向左。
- 结论（根据图示判断）：方案 B 里墙在柜体**左侧**，左侧板贴墙，角码竖边夹在左侧板和墙之间。图上没有文字说明为什么要这样摆，**仍有不确定**。
